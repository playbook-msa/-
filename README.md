# Mutiny SA — Tool Playbooks

Interactive onboarding playbooks for the ALX Creative Economy Programme.
Built with React + Vite, deployed on GitHub Pages.

## 🚀 Deploy in 5 minutes

### Step 1: Create a GitHub repo
1. Go to [github.com/new](https://github.com/new)
2. Name it `mutiny-playbooks`
3. Set it to **Public**
4. Do **NOT** add a README (we already have one)
5. Click **Create repository**

### Step 2: Push this project
Open your terminal and run these commands (replace `YOUR-USERNAME` with your GitHub username):

```bash
cd mutiny-playbooks
git init
git add .
git commit -m "Initial commit - Mutiny Tool Playbooks"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/mutiny-playbooks.git
git push -u origin main
```

### Step 3: Enable GitHub Pages
1. Go to your repo on GitHub
2. Click **Settings** → **Pages** (in the left sidebar)
3. Under **Source**, select **GitHub Actions**
4. Wait 1–2 minutes for the workflow to run

### Step 4: Visit your site
Your playbook will be live at:
```
https://YOUR-USERNAME.github.io/mutiny-playbooks/
```

## 🔧 Local development

```bash
npm install
npm run dev
```

Open http://localhost:5173 in your browser.

## 📝 Making changes

Edit the content in `src/ToolPlaybooks.jsx` and push to `main` — GitHub Actions will automatically rebuild and redeploy.
